# Kit comercial

Do primeiro contato à assinatura. Os textos jurídicos são **modelos para o Brasil** — revise com um advogado antes de usar; fora do Brasil, use só como roteiro.

| Arquivo | Para quê |
|---|---|
| [abordagem.md](abordagem.md) | Primeiro contato, roteiro da reunião de 40 minutos, objeções |
| [precificacao.md](precificacao.md) | Estrutura de preço e a regra de 1/3 do recuperável |
| [proposta-modelo.md](proposta-modelo.md) | Proposta em texto, com campos para preencher |
| **`app/proposta.html`** | **Gerador**: botão "Gerar proposta" no Raio-X monta a proposta com os números do cliente (PT/EN/ES), imprime em PDF |
| [contrato.md](contrato.md) | Contrato de prestação de serviços: obrigação de meio, bônus só sobre o atribuível, saída com 30 dias, dados do cliente são do cliente |
| [termo-lgpd.md](termo-lgpd.md) | (A) termo de tratamento de dados (cliente controlador, você operador); (B) registro de legítimo interesse da sua prospecção; (C) textos de consentimento para clube, hóspede e paciente |

**Ordem de uso:** abordagem → Raio-X com o dono → gerar proposta → contrato + termo LGPD (Anexo III) → implantação → Painel de Recuperação todo mês.
